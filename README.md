# Java HTTP Server

A single-threaded HTTP server built from scratch in Java using TCP sockets.

> 🚧 Work in Progress

## Goal

Build an HTTP server from scratch to understand how HTTP and web servers work internally, without relying on an HTTP server framework.

## Current Progress

- [x] Command-line configuration
- [x] Configurable port
- [x] Configurable directory
- [x] TCP server using `ServerSocket`
- [x] Accept client connections
- [x] Read HTTP requests
- [x] Parse HTTP request line
- [x] Parse HTTP methods
- [x] Parse HTTP headers

## Tech Stack

- Java
- Maven
- Java Networking APIs
- TCP Sockets

## Status

Currently implementing HTTP response handling and static file serving.
